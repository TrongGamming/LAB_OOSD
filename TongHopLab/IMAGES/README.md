# Đối chiếu hình và file nguồn

Các file `.puml` được mở/chỉnh sửa bằng PlantUML hoặc plugin PlantUML trong IDE; `.mdj` bằng StarUML. Các wireframe dùng SALT trong PlantUML. Thư mục này giữ nguồn mô hình, không thay bằng ảnh xuất. Mô hình `.mdj` LAB 07 được giữ như tài liệu bổ sung; nguồn chính xác dùng cho hình trong Word là `.puml` ghi ở bảng.

LAB 0 chỉ có ảnh chụp môi trường. Ảnh chụp ứng dụng WinForms trong phần triển khai minh họa sản phẩm chạy; không phải mô hình UML. Bộ nguồn được chuẩn bị local; cần tự tải lên GitHub theo hướng dẫn đi kèm.

Mỗi dòng dưới đây xác định đúng mô hình đã dùng để render hình trong báo cáo. Các hình chụp môi trường và ảnh chạy WinForms không phải sơ đồ UML; giữ nguyên trong Word để minh họa kết quả.
